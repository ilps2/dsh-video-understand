## 项目概述

dsh-video-understand 是一个低成本视频理解插件，为 dsh agent 注册 `video_understand` 工具。

**核心功能**：
- B站链接 / BV 号 / 本地视频 → AVIS 信息层 → 摘要+问答
- Token 压缩 99.95%+，成本约 0.006 元/视频
- 支持 L0（本地）、L1（VLM 视觉摘要）、L2（时间窗证据）三级理解

## 入口和参数

### Node 入口（dsh/index.js）

```javascript
video_understand(target, questions?, noDownload?, level?, window?)
```

| 参数 | 类型 | 说明 |
|------|------|------|
| target | string | B站 URL / BV 号 / 本地视频绝对路径 |
| questions | string[] | 可选，自定义问题（默认 3 问） |
| noDownload | boolean | 本地文件置 true |
| level | string | `l0`(默认) / `l1` / `l2` |
| window | string | L2 时间窗，如 `10-30` |

### Python 引擎（engine/understand_video.py）

```bash
python3 understand_video.py <target> [--ask "问题"] [--no-download] [--level l0|l1|l2] [--window 10-30]
```

## Node → Python 调用

1. Node 通过 `spawn` 调用 Python 脚本
2. 传递参数：target、questions、noDownload、level、window
3. Python 输出 JSON 到 stdout
4. Node 解析 JSON 并返回给 dsh agent

## L0/L1/L2 实际路径

### L0（默认，完全本地）
1. 下载视频（360p）
2. 提取音频 → ASR 转写
3. 场景分类
4. 运动对象检测（MOG2 + YOLO）
5. 融合 prompt → LLM 摘要+问答

### L1（VLM 视觉摘要）
1. L0 基础上
2. 抽取 3-5 帧关键帧
3. 发送到 MiMo API 进行 VLM 分析
4. 补充视觉信息

### L2（时间窗证据）
1. L0 基础上
2. 用户指定时间窗
3. 密集抽帧
4. 发送到 MiMo API 进行时间线分析
