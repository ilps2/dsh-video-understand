# 对照实验：信息层方案 vs 基线方案（0.5.0 发版验证）

目的：用数据回答"低成本视频理解在 2026 年还有没有价值"。
对比本项目的 AVIS 信息层路线与两个基线：字幕直取、均匀抽帧直发 VLM。

## 实验组

| 组 | 方案 | 运行方式 |
|---|---|---|
| **A · 引擎默认** | 本项目信息层（ASR+场景+轨迹 → 文本 → LLM，默认 3 问） | `understand_video.py <target> --json` |
| **B · 引擎视觉** | 同一引擎 + 视觉细节问题（触发视觉聚焦/L2 证据） | `understand_video.py <target> --ask "穿着/色调/动作细节..." --json` |
| **C · 字幕基线** | B站 CC/自动字幕直取 → 纯文本喂 MiMo | `yt-dlp --write-auto-subs --sub-lang zh-CN --skip-download <url>`，字幕全文 + 问题 → `mimo-v2.5` |
| **D · 抽帧基线** | 无信息层，每 30s 均匀抽 1 帧（JPEG）直发 MiMo VLM + 问题 | `ffmpeg -i video.mp4 -vf fps=1/30 f_%03d.jpg` → MiMo 多模态 |
| **E · 原生视频** | 零预处理，视频本体经 `video_url` 直发 mimo-v2.5（官方多模态格式，fps=2） | `python3 experiments/baseline_e_native.py <BV> --json` |

C/D 两个基线的调用脚本见 `experiments/baseline_c_subtitle.py` 与 `experiments/baseline_d_frames.py`（如缺失，按上表命令手工执行即可）。

## 样本视频（3 类 × 1 个，时长 5-15 分钟）

| 类别 | 选片标准 | 考察点 |
|---|---|---|
| 电影解说 | 语音密集、有 CC 字幕 | A/C 应接近；验证信息层是否丢失情节细节 |
| 舞蹈/运动 | 几乎无语音、视觉密集 | C 应接近零分；A vs B/D 检验视觉信息获取能力 |
| 教程（编程/烹饪） | 语音 + 画面并重 | 检验"画面有但没说"的信息（代码、食材克数） |

固定 **10 道问题**（每视频同一套）：核心内容概括 ×2、细节事实 ×4（人名/数字/物品/时间）、推断 ×2（适合人群/作者意图）、视觉细节 ×2（穿着/色调/动作）。

## 指标（每组每视频记录）

| 指标 | 来源 |
|---|---|
| 端到端耗时（s） | 计时 |
| 总成本（元） | A/B 读返回的 `cost_cny`；C/D 按 token 用量 × MiMo 单价计算 |
| 输入 token | API 返回 usage |
| 答案质量（1-5 分/题） | 盲评：打乱组别顺序后人工打分，维度=事实正确/细节覆盖/无幻觉 |
| 二次追问成本 | 同一视频换 3 个新问题再跑一遍，记录边际成本（检验缓存优势） |

## 判定标准（预先约定，避免事后解释）

- **项目定位成立**（押注批量+隐私）：A 组质量均分 ≥ C 组 90%，且成本 ≤ C/D 的 1/5；或批量 10 视频场景总成本领先 ≥ 一个数量级
- **定位需收缩到隐私场景**：C 组在解说/教程类质量持平且成本相近，但舞蹈类 A/B 明显胜 C —— README 主卖点从"成本"改为"本地隐私 + 视觉覆盖"
- **项目价值存疑**：E 组（原生视频）质量全面 ≥ B 且成本差距 < 3 倍 —— 考虑归档或转型为 B站 agent 工具链壳（E 组是主要判据，D 组为参考）

## 注意事项

- 每个视频每条臂只跑 3 次取中位数（MiMo 有缓存，首次/二次分开记录）
- 盲评人不看组别标签，只看答案文本
- 跑之前确认 `LLM_MODEL=mimo-v2.5`，四组用同一模型，排除模型差异
